# Chấm công Teid

Web app chấm công – nghỉ phép – quản lý nhân sự (~20 người).

```
node server/server.js     # hoặc double-click start.bat
```
Mở http://localhost:3000 — admin: `admin@company.vn / admin123`, nhân viên: `nv02@company.vn / 123456`.

Xem `CLAUDE.md` (cấu trúc, quy ước), `MEMORY.md` (quyết định, TODO), `Document/` (tài liệu).
