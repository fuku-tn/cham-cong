# Starttrain — Chấm công

Web app chấm công – nghỉ phép – quản lý nhân sự. Một người phụ trách chấm công thay cho toàn bộ nhân viên.

```
node server/server.js     # hoặc double-click start.bat
```
Mở http://localhost:3000 — đăng nhập lần đầu `admin@starttrain.vn / admin123` (đổi mật khẩu ngay).

Danh sách nhân viên: đặt `Employee.xlsx` (cột Tên, Chức vụ) rồi chạy `python scripts/import-employees.py`.
Xem `CLAUDE.md` (cấu trúc, quy ước), `MEMORY.md` (quyết định, TODO), `Document/` (tài liệu).
