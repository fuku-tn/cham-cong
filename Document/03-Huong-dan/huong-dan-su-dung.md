# Hướng dẫn sử dụng

1. Chạy `start.bat` (hoặc `node server/server.js`), mở http://localhost:3000.
2. Đăng nhập (xem tài khoản demo trong README).
3. **Chấm công**: trang "Chấm công & Nghỉ phép" → bấm *Chấm công vào* khi đến, *Chấm công ra* khi về.
4. **Xin nghỉ**: bấm *+ Xin nghỉ phép*, chọn loại/ngày/lý do → chờ HR duyệt.
5. **HR**: trang "Quản lý nhân sự" → tab *Duyệt nghỉ phép* để duyệt; tab *Nhân viên* để thêm/sửa; tab *Bảng công tháng* để xem tổng hợp.
6. **Sao lưu**: `npm run backup`. **Làm lại dữ liệu mẫu**: `npm run reset-data` rồi chạy lại server.
